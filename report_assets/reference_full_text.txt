CHAPTER 1
INTRODUCTION
The SmartRent Rental Management Portal is a web-based application developed to
manage and organize rental products digitally. It is designed to replace traditional manual
methods of managing product rentals, booking requests, rental periods, payments, and
product returns. The system provides a convenient platform for users to rent products such as
books, cameras, and laptops for a specified period. It uses the MERN stack, which includes
MongoDB, Express.js, React.js, and Node.js, to provide an efficient and user-friendly rental
management solution.
The system provides two types of users: User and Admin, each having specific roles
and access privileges. Users can register, log in, browse available products, search by
category, select rental durations from one to seven days, submit rental requests, and view
their rental history. The system calculates the total rental amount based on the selected
product and rental duration. It also provides a demo payment facility and allows users to track
the status of their rental requests.
The Admin can add, update, and delete products, manage product availability, review
rental requests, approve or reject bookings, monitor rental periods, and manage product
returns and damage reports. The system also supports email notifications to inform users
about important rental activities, including booking confirmations, approval or rejection of
requests, and return updates.
The SmartRent Rental Management Portal helps maintain accurate rental records,
reduces manual errors, saves time, and improves the overall efficiency of rental operations. It
enhances transparency by providing clear rental information and controlling access to
administrative functions. The responsive and user-friendly interface enables users and
administrators to manage rental activities efficiently. This system is useful for rental
businesses and individuals who want to manage products and rental services in a more
organized, convenient, and reliable manner.

CHAPTER 3
DESCRIPTION
The SmartRent Rental Management Portal is a web-based application designed to manage
rental products, booking requests, and product availability efficiently. The system includes
two types of users: User and Admin. The Admin has the ability to add, update, and delete
rental products such as books, cameras, and laptops, manage product availability, and
monitor rental requests. All information is stored in a MongoDB database for easy access and
management.
Users can register and log in to browse available products, search by category, select rental
durations from one to seven days, and submit rental requests. The system automatically
calculates the total rental amount based on the selected product and rental period. Users can
also access the demo payment facility, view their rental history, and track the status of their
bookings. The Admin can approve or reject rental requests, manage product returns, and
record damage reports.
The system ensures secure access through JWT-based authentication and role-based
authorization, providing a user-friendly and responsive interface for all users. It also supports
email notifications to inform users about booking updates and rental activities. This project
helps reduce manual work, minimize errors, improve rental management efficiency, and
maintain organized digital records of products, users, and rental transactions. It provides a
convenient and reliable solution for managing rental services through a centralized web
application.

TECH STACK
Frontend Technologies: React.js, Vite, HTML5, CSS3, JavaScript
Backend Technologies: Node.js, Express.js
Middleware: JWT Authentication Middleware, Authorization Middleware, CORS
Middleware, Express JSON Middleware
Database: MongoDB, Mongoose ODM
Additional Technologies: Axios for API communication, bcryptjs for password hashing,
Nodemailer for email notifications, JSON Web Token (JWT) for authentication
Approach: RESTful API Design, Asynchronous Programming using Async/Await, Modular

Architecture: MVC (Model-View-Controller)
•
Models: Mongoose models representing database entities such as User, Product, Rental, and
Notification.
•
Views: React components responsible for user interface rendering, product browsing, rental
booking, payment demonstration, and admin dashboard interactions.
•
Controllers: Express.js route handlers responsible for business logic, authentication, product
management, rental requests, booking approvals, and API responses.
•
Routes: Express.js routes that connect frontend requests to the appropriate controllers and
backend services.
•
Database: MongoDB stores user accounts, product details, rental records, booking statuses,
and notification information.
•
Services: Backend services handle email notifications and other reusable business operations.

BACKEND FOLDER STRUCTURE
Fig 8.1 – Backend Folder Structure
The SmartRent backend folder structure organizes the application into routes, controllers,
models, services, and middleware. Routes handle API requests, controllers process
application logic, and models manage MongoDB data using Mongoose. Services handle
reusable operations, while middleware manages authentication and authorization. This
modular structure improves code readability, maintainability, debugging, and backend
functionality.


=== PAGE 15 ===
14
Fig 8.2 Backend Routes
In the SmartRent Rental Management Portal, the routes and services form the core of the
backend architecture, ensuring modularity, readability, and maintainability. The backend is developed
using Node.js and Express.js, while MongoDB is used to store user details, product information,
rental requests, and notification records. Routes define the endpoints through which the React
frontend communicates with the backend. Each route handles a specific operation, such as user
authentication, product management, rental booking, booking approval, payment demonstration, and
notification management. HTTP methods such as GET, POST, PUT, and DELETE are used to
retrieve, create, update, and delete records.
Services handle reusable business operations and database interactions using Mongoose. They
manage operations such as calculating rental amounts, checking product availability, preventing
conflicting bookings, updating rental statuses, and sending email notifications. Authentication and
authorization middleware protect restricted endpoints and ensure that only authorized users can
perform administrative operations. Together, routes, controllers, and services create a structured and
scalable backend architecture that improves code reusability, simplifies debugging, and supports the
efficient operation of the SmartRent Rental Management Portal.
